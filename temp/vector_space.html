🧠 Vector Spaces & Subspaces: Interactive Learning

▶ 1. What is a Vector Space?

📘 Definition

A vector space V over the real numbers ℝ is a set equipped with two operations:

  • Vector Addition: u + v ∈ V
  • Scalar Multiplication: c·u ∈ V (where c ∈ ℝ)

These operations must satisfy 8 axioms:

1. Closure under Addition

u + v ∈ V

2. Commutativity

u + v = v + u

3. Associativity of Addition

(u + v) + w = u + (v + w)

4. Zero Vector

∃ 0 : u + 0 = u

5. Additive Inverse

∃ -u : u + (-u) = 0

6. Closure under Scalar Mult.

c·u ∈ V

7. Distributivity

c(u + v) = cu + cv

8. Scalar Identity

1·u = u

✅ Examples of Vector Spaces

  • ℝⁿ: The set of all n-dimensional vectors
  • Mm×n: The set of all m×n matrices
  • Pn: The set of all polynomials of degree ≤ n
  • C[a,b]: The set of continuous functions on [a,b]

▶ 2. What is a Subspace?

📘 Definition

A subspace W of a vector space V is a subset of V that is itself a vector space under the same operations.

🎯 The Subspace Test (3 Conditions)

To verify that W ⊆ V is a subspace, check these three conditions:

1️⃣ Contains Zero Vector
0 ∈ W

The zero vector must be in W.

2️⃣ Closed under Addition
If u, v ∈ W ⇒ u + v ∈ W

Adding two vectors in W gives another vector in W.

3️⃣ Closed under Scalar Multiplication
If u ∈ W, c ∈ ℝ ⇒ c·u ∈ W

Multiplying a vector in W by any scalar gives a vector in W.

💡 Key Insight

If any of these three conditions fails, W is NOT a subspace.

The most common failure is not containing the zero vector.

▶ 3. Examples: Subspaces vs Non-Subspaces

✅ SUBSPACE Examples

Example 1: W = { (x, y) | x = 2y }

Set: All vectors where first component is twice the second

✓ Zero vector: (0, 0) → 0 = 2(0) ✅

✓ Addition: (2a, a) + (2b, b) = (2(a+b), a+b) ✅

✓ Scalar mult: c(2a, a) = (2(ca), ca) ✅

✅ This IS a subspace of ℝ²

Example 2: W = { (x, y, z) | x + y + z = 0 }

Set: All vectors whose components sum to zero

✓ Zero vector: 0 + 0 + 0 = 0 ✅

✓ Addition: If x₁+y₁+z₁=0 and x₂+y₂+z₂=0, then (x₁+x₂)+(y₁+y₂)+(z₁+z₂)=0 ✅

✓ Scalar mult: If x+y+z=0, then c·x + c·y + c·z = c(x+y+z) = 0 ✅

✅ This IS a subspace of ℝ³ (a plane through origin)

Example 3: W = { (x, 0, z) | x, z ∈ ℝ }

Set: The xz-plane in ℝ³

✓ Zero vector: (0, 0, 0) ∈ W ✅

✓ Addition: (x₁, 0, z₁) + (x₂, 0, z₂) = (x₁+x₂, 0, z₁+z₂) ∈ W ✅

✓ Scalar mult: c(x, 0, z) = (cx, 0, cz) ∈ W ✅

✅ This IS a subspace of ℝ³

❌ NON-SUBSPACE Examples

Example 1: W = { (x, y) | x = 2y + 1 }

Set: A line not through the origin

✗ Zero vector: (0, 0) → 0 ≠ 2(0) + 1 ❌

FAILS: Zero vector not in W!

❌ NOT a subspace (doesn't contain origin)

Example 2: W = { (x, y, z) | x + y + z = 1 }

Set: A plane not through the origin

✗ Zero vector: 0 + 0 + 0 ≠ 1 ❌

FAILS: Zero vector not in W!

❌ NOT a subspace

Example 3: W = { (x, y) | x ≥ 0, y ≥ 0 }

Set: First quadrant

✓ Zero vector: (0, 0) ∈ W ✅

✓ Addition: Sum of non-negative is non-negative ✅

✗ Scalar mult: (-1)(1, 1) = (-1, -1) ∉ W ❌

FAILS: Not closed under scalar multiplication!

❌ NOT a subspace

▶ 4. Span, Linear Independence & Basis

📘 Span

The span of a set of vectors {v₁, v₂, ..., vₖ} is the set of all possible linear combinations:

Span{v₁, v₂, ..., vₖ} = {c₁v₁ + c₂v₂ + ... + cₖvₖ | c₁, c₂, ..., cₖ ∈ ℝ}

Key fact: The span is always a subspace!

📘 Linear Independence

Vectors {v₁, v₂, ..., vₖ} are linearly independent if:

c₁v₁ + c₂v₂ + ... + cₖvₖ = 0 ⟹ c₁ = c₂ = ... = cₖ = 0

In other words: The only way to get zero is with all zero coefficients.

Otherwise: They are linearly dependent (one is a combination of others).

📘 Basis

A basis for a subspace W is a set of vectors that:

  • 1. Spans W (every vector in W can be written as their combination)
  • 2. Is linearly independent

Dimension: The number of vectors in a basis = dim(W)

🔍 Example: Standard Basis for ℝ³

e₁ = (1, 0, 0), e₂ = (0, 1, 0), e₃ = (0, 0, 1)

These three vectors:

  • ✅ Are linearly independent
  • ✅ Span all of ℝ³
  • ✅ Form a basis for ℝ³
  • ✅ dim(ℝ³) = 3

▶ 5. Interactive Practice Problems

Problem 1

Is W = { (x, y, z) | 2x - y + 3z = 0 } a subspace of ℝ³?

Answer: YES ✅

1. Zero vector: 2(0) - 0 + 3(0) = 0 ✓

2. Closed under addition ✓

3. Closed under scalar multiplication ✓

This is a plane through the origin, which is a subspace.

Problem 2

Is W = { (x, y) | xy = 0 } a subspace of ℝ²?

Answer: NO ❌

1. Zero vector: (0)(0) = 0 ✓

2. But: (1, 0) ∈ W and (0, 1) ∈ W

However: (1, 0) + (0, 1) = (1, 1), and (1)(1) = 1 ≠ 0

So (1, 1) ∉ W ✗

FAILS closure under addition!

Problem 3

Are vectors v₁ = (1, 2, 3) and v₂ = (2, 4, 6) linearly independent?

Answer: NO, they are DEPENDENT ❌

Notice: v₂ = 2·v₁

So: 2v₁ - v₂ = 0 with non-zero coefficients

These vectors are linearly dependent.

They span a 1-dimensional subspace (a line).
