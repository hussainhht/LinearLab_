1.1 Introduction to Systems of Linear Equations

📖 What is a System of Linear Equations?

A system of linear equations is a collection of linear equations involving the same set of variables.

General Form

Consider the following system with n equations and p variables (unknowns):

a₁₁x₁ + a₁₂x₂ + ... + a₁ₚxₚ = b₁
a₂₁x₁ + a₂₂x₂ + ... + a₂ₚxₚ = b₂
...
aₙ₁x₁ + aₙ₂x₂ + ... + aₙₚxₚ = bₙ

Where:

  • aᵢⱼ are coefficients (numbers)
  • xⱼ are variables (unknowns)
  • bᵢ are constants
  • n = number of equations
  • p = number of variables

💡 Key Point

This system is called a system of n linear equations and p variables.

1.2 Definition & Notation

Examples of Systems

Example (a): 2 equations and 3 variables

x - 3y + z = 1
2x + 4y + 5z = 2

This system has 2 equations and 3 variables (x, y, z).

Example (b): 1 equation and 4 variables

x + y - z + t = 0

This system has 1 equation and 4 variables (x, y, z, t).

Example (c): 2 equations and 4 variables

x₁ + 2x₂ + 3x₃ + 4x₄ = 1
x₁ - 2x₃ = -1

Note: Some coefficients are zero (0x₂, 0x₄ in the second equation).

1.3 Classification Examples

What ARE Linear Equations?

✓ Linear Equations:

  • 3x + 2y = 7
  • x - y + z = 0
  • 5x₁ - 2x₂ + x₃ = 10
  • y = 2x + 3

All variables have power of 1, no products of variables

What are NOT Linear Equations?

✗ Non-Linear Equations:

  • x² + y = 5 (power of 2)
  • xy + z = 1 (product of variables)
  • sin(x) + y = 0 (trigonometric function)
  • √x + y = 3 (square root)

These violate the linearity condition

1.4 Solution Sets

📖 What is a Solution?

A solution to a system of linear equations is a set of values for the variables that satisfies ALL equations simultaneously.

Types of Solution Sets

1️⃣ Unique Solution

The system has exactly ONE solution.

x + y = 3
x - y = 1

Solution: x = 2, y = 1

2️⃣ Infinitely Many Solutions

The system has INFINITE solutions.

x + y = 3
2x + 2y = 6

Solution: x = t, y = 3 - t (for any t)

3️⃣ No Solution

The system is inconsistent (contradictory).

x + y = 3
x + y = 5

No solution possible!

2.1 Matrix Basics

📖 What is a Matrix?

A matrix is a rectangular array of numbers arranged in rows and columns.

Matrix Notation

A matrix with m rows and n columns is called an m × n matrix.

[
a₁₁ a₁₂ ... a₁ₙ
a₂₁ a₂₂ ... a₂ₙ
... ... ... ...
aₘ₁ aₘ₂ ... aₘₙ
]

Key Terms

  • Entry/Element: Each individual number in the matrix (aᵢⱼ)
  • Row: Horizontal line of entries
  • Column: Vertical line of entries
  • Dimension/Size: m × n (rows × columns)

Example: 3 × 2 Matrix

[
1 2
3 4
5 6
]

This has 3 rows and 2 columns.

2.2 Matrix Operations

Matrix Addition

Matrices of the same size can be added by adding corresponding entries.

Example:

[1 2] [5 6] [6 8]
[3 4] + [7 8] = [10 12]

Scalar Multiplication

Multiply every entry of the matrix by a scalar (number).

Example:

3 × [1 2] = [3 6]
    [3 4]   [9 12]

Matrix Multiplication

Important Rules:

  • To multiply A × B, the number of columns in A must equal the number of rows in B
  • If A is m × n and B is n × p, then A × B is m × p
  • Matrix multiplication is NOT commutative: A × B ≠ B × A

2.3 Special Matrices

1️⃣ Zero Matrix

All entries are zero.

[
0 0
0 0
]

2️⃣ Identity Matrix (I)

Square matrix with 1's on the diagonal and 0's elsewhere.

[
1 0 0
0 1 0
0 0 1
]

Property: A × I = I × A = A

3️⃣ Diagonal Matrix

All non-diagonal entries are zero.

[
5 0 0
0 3 0
0 0 -2
]

2.4 Matrix Properties

Addition Properties

  • Commutative: A + B = B + A
  • Associative: (A + B) + C = A + (B + C)
  • Zero Matrix: A + 0 = A

Multiplication Properties

  • Associative: (AB)C = A(BC)
  • Distributive: A(B + C) = AB + AC
  • Identity: AI = IA = A
  • NOT Commutative: AB ≠ BA (in general)

⚠️ Important Warning!

Unlike regular numbers, matrix multiplication is NOT commutative. This means the order matters!

Example: If A is 2×3 and B is 3×2:

  • A × B is possible (results in 2×2 matrix)
  • B × A is possible (results in 3×3 matrix)
  • Clearly A × B ≠ B × A (different sizes!)

3.1 Elementary Row Operations

📖 What are Row Operations?

Elementary row operations are operations we can perform on a matrix that don't change the solution set of the system.

Three Types of Row Operations

1️⃣ Row Swap (Interchange)

Swap two rows.

Notation: R₁ ↔ R₂

Example: Exchange row 1 and row 2

2️⃣ Row Scaling (Multiplication)

Multiply a row by a non-zero constant.

Notation: kR₁ → R₁

Example: Multiply row 1 by 3

3️⃣ Row Addition (Replacement)

Add a multiple of one row to another row.

Notation: R₂ + kR₁ → R₂

Example: Add 2 times row 1 to row 2

💡 Why do these operations work?

These operations preserve the solution set because they are equivalent to operations you can do on equations without changing their solutions!

3.2 Row Echelon Form (REF)

📖 Row Echelon Form

A matrix is in Row Echelon Form if it satisfies these conditions:

Conditions for REF

  • All zero rows are at the bottom
  • The first non-zero entry in each row (called the pivot) is to the right of the pivot in the row above
  • All entries in a column below a pivot are zeros

✓ Example of REF:

[
2 3 4 5
0 1 2 3
0 0 5 1
]

Pivots (highlighted) form a "staircase" pattern going down and to the right.

Slide 10 of 24

3.3 Reduced Row Echelon Form (RREF)

📖 Reduced Row Echelon Form

A matrix is in RREF if it's in REF AND:

Additional Conditions for RREF

  • Each pivot is equal to 1
  • Each pivot is the only non-zero entry in its column

✓ Example of RREF:

[
1 0 0 5
0 1 0 3
0 0 1 2
]

Notice: All pivots are 1, and are the only non-zero entry in their column.

💡 Why is RREF useful?

RREF makes it very easy to read off the solutions to a system of equations! Each variable corresponding to a pivot column has a unique value.

3.4 Solving Systems using RREF

The Process

  1. Write the augmented matrix [A|b] for the system
  2. Use row operations to transform to RREF
  3. Read the solution from the RREF

Example: Solve the System

x + 2y = 5
3x - y = 4

Step 1: Augmented matrix

[
1 2 5
3 -1 4
]

Step 2: After RREF

[
1 0 1
0 1 2
]

Step 3: Read solution

x = 1, y = 2

4.1 Introduction to Vectors

📖 What is a Vector?

A vector is an ordered list of numbers, representing a point or direction in space.

Vector Notation

Vectors can be written as column matrices or using arrow notation:

v = [v₁, v₂, v₃]ᵀ or v⃗ = ⟨v₁, v₂, v₃⟩

Example: 3D Vector

[
2
-3
5
]

This vector has components: x = 2, y = -3, z = 5

6.1 Matrix Multiplication

📖 How to Multiply Matrices

To find entry (i,j) in the product C = AB:

Multiply row i of A by column j of B and sum the products.

cᵢⱼ = aᵢ₁b₁ⱼ + aᵢ₂b₂ⱼ + ... + aᵢₙbₙⱼ

Example:

[1 2] [5 6] [1×5+2×7 1×6+2×8] [19 22]
[3 4] × [7 8] = [3×5+4×7 3×6+4×8] = [43 50]
