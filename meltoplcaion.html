For matrices A (size r×n) and B (size n×p):
cij = ai1b1j + ai2b2j + ... + airbrj

📌 Important Rules:

  • Number of columns in A must equal number of rows in B
  • Result matrix C will have size: rows of A × columns of B
  • Each element cij is calculated by multiplying row i of A with column j of B
